# Boss直聘自动点击功能执行文档

## 概述

本文档描述 `src/content/zhipin.ts` 中集成的自动点击功能，通过 Chrome 扩展消息通信机制，实现对 Boss直聘页面元素的批量自动点击操作。

## 功能特性

- **消息触发**：通过 `chrome.runtime.sendMessage` 触发自动点击
- **容器限定**：支持在指定容器内查找目标元素
- **进度回调**：实时发送点击进度到 background/popup
- **停止控制**：支持随时停止正在进行的点击操作
- **主世界注入**：自动注入到页面主世界，解决 React 框架事件触发问题

## 消息接口

### 1. startAutoClick - 启动自动点击

启动批量自动点击操作。

#### 请求参数

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| action | string | 是 | - | 固定值 `'startAutoClick'` |
| selector | string | 是 | - | CSS 选择器，选择要点击的元素 |
| delay | number | 否 | 3000 | 每次点击间隔时间（毫秒） |
| maxRetries | number | 否 | 3 | 单元素点击失败重试次数 |
| stopOnError | boolean | 否 | false | 遇到错误是否立即停止 |
| containerSelector | string | 否 | - | 容器选择器，限定查找范围 |

#### 返回值

```typescript
interface AutoClickResult {
  success: boolean;           // 是否有成功点击的元素
  successCount: number;       // 成功点击数量
  totalCount: number;         // 总元素数量
  errors: Array<{             // 错误信息数组
    index: number;            // 出错元素索引
    error: string;            // 错误描述
  }>;
  stopped: boolean;           // 是否被手动停止
}
```

### 2. stopAutoClick - 停止自动点击

停止正在进行的自动点击操作。

#### 请求参数

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| action | string | 是 | - | 固定值 `'stopAutoClick'` |

#### 返回值

```typescript
{
  success: boolean;           // 是否成功停止
  stopped: boolean;           // 是否已停止
}
```

### 3. isAutoClicking - 检查点击状态

检查是否正在执行自动点击操作。

#### 请求参数

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| action | string | 是 | - | 固定值 `'isAutoClicking'` |

#### 返回值

```typescript
{
  clicking: boolean;          // 是否正在点击
}
```

### 4. 进度通知消息

自动点击过程中，会主动发送以下消息：

#### autoClickProgress - 进度通知

```typescript
{
  action: 'autoClickProgress';
  current: number;            // 当前点击序号（从1开始）
  total: number;              // 总元素数量
}
```

#### autoClickComplete - 完成通知

```typescript
{
  action: 'autoClickComplete';
  successCount: number;       // 成功点击数量
  totalCount: number;         // 总元素数量
}
```

## 示例代码

### 示例 1：从 Popup 启动自动点击

```typescript
// popup.vue 或其他组件
const startClick = async () => {
  try {
    const [tab] = await chrome.tabs.query({ active: true, currentWindow: true });
    if (!tab?.id) return;

    const result = await chrome.tabs.sendMessage(tab.id, {
      action: 'startAutoClick',
      selector: '.geek-item',
      delay: 3000,
    });

    console.log('点击结果:', result);
  } catch (error) {
    console.error('启动失败:', error);
  }
};
```


## 核心实现

### 消息监听流程

```
popup/background
       │
       ▼ sendMessage
zhipin.ts content script
       │
       ▼ 解析 action
┌─────────────────────────┐
│ startAutoClick          │
│   ├─ 检查状态           │
│   ├─ 查找元素           │
│   ├─ 注入主世界         │
│   └─ 执行点击循环       │
├─────────────────────────┤
│ stopAutoClick           │
│   └─ 设置停止标志       │
├─────────────────────────┤
│ isAutoClicking          │
│   └─ 返回状态           │
└─────────────────────────┘
       │
       ▼ sendMessage (进度/完成)
popup/background
```

### zhipin.ts 关键代码

```typescript
// 导入自动点击工具
import { startAutoClick, stopAutoClick, isAutoClicking, injectAutoClickToMainWorld } from '../utils/autoClick';

// 注入主世界 API
injectAutoClickToMainWorld();

// 消息监听
chrome.runtime.onMessage.addListener((msg, _sender, sendResponse) => {
  if (msg.action === 'startAutoClick') {
    // 检查是否正在执行
    if (isAutoClicking()) {
      sendResponse({ success: false, error: '正在执行自动点击' });
      return false;
    }

    // 执行自动点击
    startAutoClick({
      selector: msg.selector,
      delay: msg.delay || 3000,
      maxRetries: msg.maxRetries || 3,
      stopOnError: msg.stopOnError || false,
      onProgress: (current, total) => {
        chrome.runtime.sendMessage({ action: 'autoClickProgress', current, total });
      },
      onComplete: (successCount, totalCount) => {
        chrome.runtime.sendMessage({ action: 'autoClickComplete', successCount, totalCount });
      },
    }).then(result => sendResponse(result));

    return true; // 异步响应
  }

  if (msg.action === 'stopAutoClick') {
    stopAutoClick();
    sendResponse({ success: true, stopped: true });
  }

  if (msg.action === 'isAutoClicking') {
    sendResponse({ clicking: isAutoClicking() });
  }
});
```

## 错误处理

| 错误类型 | 处理方式 | 返回结果 |
|----------|----------|----------|
| 正在执行中 | 拒绝启动 | `{ success: false, error: '正在执行自动点击' }` |
| 容器不存在 | 拒绝启动 | `{ success: false, error: '容器元素不存在' }` |
| 未找到元素 | 拒绝启动 | `{ success: false, error: '未找到目标元素' }` |
| 元素点击失败 | 重试 maxRetries 次 | 记录到 errors 数组 |
| 手动停止 | 中断点击循环 | `{ stopped: true }` |

## 注意事项

### 1. 主世界注入

- `injectAutoClickToMainWorld()` 在脚本加载时自动执行
- 将自动点击 API 注入到页面主世界，解决 React 框架事件无法触发的问题
- 注入的 API 可通过 `window.__autoClickApi` 访问

### 2. 选择器策略

- Boss直聘页面使用 React 框架，元素 class 可能动态生成
- 建议使用稳定的选择器，如 `[data-testid]` 属性或组合选择器
- 避免依赖动态生成的 class name

### 3. 速率限制

- 默认点击间隔为 3000ms，建议根据实际需求调整
- 过快的点击可能被网站识别为自动化操作
- 推荐设置 delay >= 2000ms

### 4. CSP 限制

- Content Script 运行在隔离世界，无法直接访问页面 JavaScript 上下文
- 通过主世界注入解决事件触发问题
- 避免使用 `chrome.scripting.executeScript` 传入 async 函数（可能被 CSP 拦截）

## 接口汇总

| 消息 action | 方向 | 说明 |
|-------------|------|------|
| `startAutoClick` | popup → content | 启动自动点击 |
| `stopAutoClick` | popup → content | 停止自动点击 |
| `isAutoClicking` | popup → content | 检查点击状态 |
| `autoClickProgress` | content → popup | 进度通知 |
| `autoClickComplete` | content → popup | 完成通知 |

## 使用流程

1. **用户在 Boss直聘页面打开插件 Popup**
2. **Popup 调用 `chrome.tabs.sendMessage` 发送 `startAutoClick` 消息**
3. **zhipin.ts 收到消息，检查状态并执行自动点击**
4. **点击过程中发送 `autoClickProgress` 进度通知**
5. **点击完成发送 `autoClickComplete` 通知**
6. **用户可随时发送 `stopAutoClick` 停止操作**
