# 简历收集插件 (Chrome Resume Plugin)

一个基于 Chrome Manifest V3 的浏览器扩展，用于自动化收集简历并上传到 HRM 系统。

## 功能特性

### 📄 Boss直聘简历收集

- **自动检测 PDF**：打开简历页面后插件自动检测，无需手动操作
- **真实下载链接提取**：通过网络请求拦截 + Blob URL 拦截 + DOM 扫描三重策略获取 PDF 真实地址
- **一键上传**：选择需求岗位后点击提交，简历自动上传到 HRM 系统
- **链接预览**：PDF 链接以「点击查看简历PDF」可点击文字展示，不再暴露原始 URL

### 📋 猎聘简历收集

- **自动拦截 API**：拦截猎聘简历查看 API 请求，自动提取候选人全部信息
- **信息自动填充**：姓名、性别、年龄、学历、工作经历、手机号、邮箱、城市等自动填充
- **简历附件检测**：自动识别并提取简历附件下载地址
- **关联需求选择**：从 HRM 系统获取招聘需求列表，支持快速关联

### 🔄 统一流程

- **选择岗位即可提交**：只需选择对应的招聘需求岗位，无需填写手机号等其他信息
- **简历状态提示**：顶部实时显示简历检测状态（绿色=已就绪 / 红色=未检测到 / 蓝色=检测中）
- **提交保护**：同一简历 5 秒内不会重复提交

## 快速开始


## 核心流程

### Boss直聘流程（优化后）

1. 用户打开 Boss直聘简历预览页面
2. Content Script 自动检测 PDF 下载链接（网络拦截 + Blob 拦截 + DOM 扫描）
3. 用户点击插件图标
4. 简历状态实时显示（已检测 / 未检测 / 检测中）
5. 选择「关联需求岗位」（必选）
6. 点击「🚀 提交简历」上传到 HRM

### 猎聘流程（优化后）

1. 用户打开猎聘简历查看页面
2. Background Script 拦截简历 API 请求，提取候选人全部信息
3. 用户点击插件图标
4. 候选人信息以卡片形式自动展示（姓名、标签、联系方式）
5. 选择「关联需求岗位」（必选）
6. 点击「🚀 提交简历」上传到 HRM

## PDF 链接提取策略

1. **网络请求拦截**：`chrome.webRequest` 拦截包含 `.pdf`、`/download/`、`/resume/`、`preview4boss` 等关键字的请求
2. **Blob URL 拦截**：main world 注入脚本，拦截 `URL.createObjectURL` 和 `fetch` 请求，捕获 PDF blob 数据
3. **DOM 扫描**：扫描页面中的 iframe、弹窗、下载按钮中的 PDF URL

## 已知限制

- 简历页面需完全加载后才能检测 PDF
- 猎聘/Boss直聘的反调试机制可能影响部分测试操作
- 上传简历需确保已登录 HRM 系统（`hrm-sit6.fcbox.com`）

### 对比总结

**共同字段（8个）**：招聘类型、职位名称、职位描述、职位类型、经验、学历、薪资范围、工作地址

**平台独有字段**：

- **Boss 直聘独有**：职位关键词
- **猎聘独有**：招聘人数、行业要求、截止日期、所属部门、职位福利、语言要求、海外经历

猎聘的职位字段比 Boss 直聘更加丰富，多出了 7 个特有字段，涵盖了招聘规模、行业限制、招聘时效、组织架构、福利、语言能力等维度。
